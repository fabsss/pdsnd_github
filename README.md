### Project Title
Bikeshare Data Analysis

### Description
This project explores bikeshare data for New York City. It allows users to filter the data by month, day, and city, and computes statistics such as the most popular travel times, stations, trip durations, and user demographics.


### Requirements
#### Software
- Python 3.6 or higher
- pandas library
- (Optional) Jupyter Notebook for interactive exploration

#### Hardware
- Any modern computer capable of running Python (Windows, macOS, or Linux)
- At least 2GB RAM recommended

### Installation Instructions
1. Ensure Python 3.6 or higher is installed. Download from https://www.python.org/downloads/
2. Install required Python packages using pip:
	```
	pip install pandas
	```
3. (Optional) Install Jupyter Notebook:
	```
	pip install notebook
	```
4. Clone or download this repository to your local machine.
5. Run the script using:
	```
	python bikeshare_starter.py
	```

### Files used
- bikeshare_starter.py: Main Python script for data analysis and user interaction.
- new_york_city.csv: Dataset containing bikeshare data for New York City.
